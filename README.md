# Менеджер задач

Простое desktop-приложение для управления задачами (Python + Tkinter).
Учебный проект: демонстрирует ООП, графический интерфейс, работу с файлами
и систему контроля версий Git.

## Функциональность

- Добавление задач: название, описание, срок выполнения (формат ГГГГ-ММ-ДД).
- Удаление выбранной задачи (с подтверждением).
- Автосохранение списка в файл `tasks.json` и загрузка при запуске.
- Проверка корректности даты перед добавлением задачи.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `classes.py` | Классы `Task` и `TaskManager` (ООП, чтение/запись JSON) |
| `gui.py` | Графический интерфейс на Tkinter (точка входа) |
| `tasks.json` | Файл хранения задач |
| `requirements.txt` | Зависимости проекта |

## Установка и запуск

1. Установите Python 3.10 или новее.
2. Создайте и активируйте виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate      # Linux/macOS
   # venv\Scripts\activate       # Windows
   ```

3. Запустите приложение:

   ```bash
   python gui.py
   ```

## Использование

1. Заполните поля «Название», «Описание» и «Срок» (например, `2025-12-31`).
2. Нажмите **Добавить** — задача появится в списке и сохранится в `tasks.json`.
3. Чтобы удалить задачу, выберите её в списке и нажмите **Удалить**.
4. Задачи автоматически загружаются из `tasks.json` при следующем запуске.
